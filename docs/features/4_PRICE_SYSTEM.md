# 💰 Price System

This document details the integrated price system, which allows the application to fetch and display real-time market prices for detected Pokémon cards.

---

## 🗺️ Card Mapping System

The foundation of the price system is the ability to link a detected card's class name (e.g., "Pikachu") to its official ID in the TCGdex database (e.g., "sv4pt5-49"). This is handled by the `card_name_to_id.json` file.

-   **File**: `models/card_name_to_id.json`
-   **Purpose**: Acts as a dictionary to map the YOLO class name to a unique card ID.
-   **Generation**: This file is automatically generated by running the `create_card_mapping` script, which analyzes your dataset.

**Example Entry**:
```json
{
  "Pikachu": "sv4pt5-49",
  "Charmander": "sv4pt5-7",
  "Iron_Crown": "sv08_132"
}
```

---

## 💵 Price Initialization & Database

Once the mapping is established, the application can fetch price data from the TCGdex API, which aggregates prices from **Cardmarket** and **TCGPlayer**.

### Price Database

-   **File**: `excel/cards_with_prices.xlsx`
-   **Purpose**: Stores all fetched price data in an easily accessible Excel file. This acts as a local cache to minimize API calls.
-   **Generation**: The file is created and updated by running one of the `init_prices` scripts.

### Initialization Scripts

| Script | Description |
| :--- | :--- |
| `init_prices` | Initializes prices for all cards present in your final `data.yaml` dataset file. |
| `init_prices_simple` | A quick test script that initializes prices for a small, predefined set of 8 cards. |
| `init_prices_real` | Initializes prices for a larger, predefined set of real cards. |

## 📹 Detection with Prices

This is where the system comes together. During live detection, the application performs the following steps in real-time:

1.  A card is detected by the YOLO model, which returns its class name (e.g., "Pikachu").
2.  The application looks up "Pikachu" in the `card_name_to_id.json` file to find its official ID.
3.  It then queries the `cards_with_prices.xlsx` database using this ID to retrieve the stored market price.
4.  The price is displayed directly on the screen as part of the bounding box overlay.

This entire process is seamless and provides instant feedback on the value of detected cards.
